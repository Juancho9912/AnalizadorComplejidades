# Analizador de Complejidades

Proyecto final de **Análisis y Diseño de Algoritmos**.

## Objetivo
Desarrollar un sistema que, a partir de un pseudocódigo estructurado, determine las complejidades:
- Peor caso (O)
- Mejor caso (Ω)
- Promedio (Θ)

```bash
pip install lark-parser
python main.py
